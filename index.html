About

關於 Build with CCU

Microsoft Build 是微軟每年針對開發者舉辦的技術大會。 這次我們將 Build 帶進校園，邀請 微軟工程師、微軟 MVP、.NET 基金會、GitHub Star 走進中正大學，與學生及開發者分享 AI、Cloud、.NET 與開源的最新資訊。

從 Build 開幕影片出發，接著三場技術主題演講。除了聽，也歡迎在現場與講者及其他參與者交流。

Schedule

當晚議程

2026 / 06 / 13（六）17:00 – 21:00

  1. 17:00 – 17:30

    入場 & 開場

    微軟 Build 開幕影片播放，現場提供 免費 Pizza、飲料、Costco 點心。輕鬆 networking、認識新朋友。

  2. 17:30 – 18:30

    Session 1 · Daniel

    微軟台灣工程師

    PostgreSQL Extension 與 Hook 機制：用 Rust pgrx 實戰拆解 redis_fdw_rs 專案

    以 redis_fdw_rs 為例，帶你了解 PostgreSQL 的 Extension 與 Hook 機制，並使用 Rust pgrx 實作一個 Foreign Data Wrapper。

  3. 18:30 – 19:30

    Session 2 · 林暐翰

    .NET 基金會 Microsoft MVP

    GitHub AI 訓練專屬知識庫開發專案

    分享如何在 GitHub 生態中打造專屬知識庫並訓練 AI 模型，以及這樣的專案是如何規劃、實作與部署的。

  4. 19:30 – 20:30

    Session 3 · 謝政廷

    台積電副理 Microsoft MVP GitHub Star

    同時是台積電副理、微軟 MVP，以及全球少數 GitHub Star 之一，分享在大型企業推動開源與 AI 的真實經驗。

  5. 20:30 – 21:00

    結尾 & 紀念禮物

    總結、Q&A 與合影，參與的每位夥伴都可獲得活動紀念帽 🧢 與其他小禮物 🎁，活動結束。
