About

關於 Build with CCU

Microsoft Build 是微軟每年針對開發者舉辦的技術大會。 這次我們將 Build 帶進校園，邀請 微軟工程師、微軟 MVP、.NET 維護者、GitHub Star 走進中正大學，與學生及開發者分享 AI、Cloud、.NET 與開源的最新資訊。

從 Build 開幕影片出發，接著三場技術主題演講。除了聽，也歡迎在現場與講者及其他參與者交流。
